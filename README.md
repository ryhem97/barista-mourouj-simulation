# Barista Mourouj — Project Initiation Simulator

An interactive classroom decision-making simulator designed for **Chapter 3: Initiating Projects**.

## 📌 Project Overview
This project simulates the initiation phase for opening a new **Barista Mourouj Branch**. Users navigate sequential project decision points, evaluating live trade-offs across key project metrics:
- **Capital Expenditure (CapEx)**
- **Schedule Duration**
- **Stakeholder Support Score**
- **Quality Audit Score**
